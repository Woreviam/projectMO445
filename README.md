# projectMO445: Image Analysis Course Project - UNICAMP

This repository contains the project developed for the **MO445 / MC940A - Image Analysis** course at the Institute of Computing (IC) at the State University of Campinas (UNICAMP), taught by Prof. Alexandre Xavier Falcão.

## Project Description

This project focuses on the practical application and implementation of various image processing and analysis techniques, primarily using the **C programming language**. The core idea is to **detect and segment parasite eggs within images using a relatively small dataset of 100 images for training, testing, and development**. To achieve this, the project makes use of **convolutional networks, specifically incorporating adaptive decoders**. In addition, it employs **graph algorithms like the [Image Foresting Transform (IFT)](https://en.wikipedia.org/wiki/Image_foresting_transform) and [watershed](https://en.wikipedia.org/wiki/Watershed_(image_processing))** for delineation of the parasite eggs.

## Course Overview (MO445 / MC940A - Image Analysis)

The MO445/MC940A course provides a comprehensive understanding of image analysis, covering both classical methods and modern approaches. Key topics typically explored in this course, and therefore likely addressed in this project, include:

* **Fundamentals of Image Processing:** Point-based, adjacency-based, and connectivity-based transforms.
* **Image Representation:** Point, region, and shape-based approaches; superpixel and hierarchical segmentation; iso-contours and multiscale skeletons.
* **Image Description:** Color, texture, shape descriptors; data clustering and bag of visual words; convolutional layers.
* **Image Filtering:** Techniques like connected operators.
* **Image Segmentation:** Image-based to model-based approaches, semantic and instance segmentation.
* **Image Classification:** Fundamentals of machine learning, from perceptron to deep convolutional neural networks.
* **Optimum-Path Forest (OPF):** Clustering and Classification by Optimum-Path Forest.
